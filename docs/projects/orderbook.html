OrderBook

Real-time limit order book and matching engine

Built a Python limit-order-book simulator implementing price-time priority matching. The engine supports limit and market orders, partial fills, cancellations, and trade history, with Decimal arithmetic for prices and quantities.

The Challenge
Matching needs to preserve FIFO priority at each price, handle partial fills and market-order sweeps, and keep prices and quantities consistent without floating-point drift.
The Solution
Organized bid and ask price levels with SortedDict and FIFO queues, using Decimal arithmetic throughout matching. Added a Textual terminal interface and an asyncio-driven market simulator to inspect order flow, fills, and book state.
The Impact
Makes matching behavior visible through a live terminal interface, with tests covering order handling and priority rules.

Key Features

> ls features/
  • ├──Price-time priority and FIFO matching within price levels
  • ├──Limit and market orders, partial fills, and cancellations
  • ├──SortedDict-backed bid and ask price levels
  • ├──Decimal-based prices and quantities
  • ├──Live Textual terminal interface
  • └──Asynchronous market simulator with configurable order flow

Content-addressed storage and deduplication in C++17

Built a C++17 deduplication engine using Rabin-fingerprint content-defined chunking and SHA-256 content addressing. A sharded concurrent index tracks stored chunks, with atomic reference counts, garbage collection, and delta replication.

The Challenge
Fixed-size boundaries can miss shared content after insertions or edits. Concurrent storage also needs coordinated index access and a reliable way to reclaim chunks after references are removed.
The Solution
Implemented Rabin-fingerprint chunking and SHA-256 chunk identifiers. The index uses sharded reader/writer locks and atomic reference counts; storage operations support deduplication, reference-counted reclamation, and replication of changed content.
The Impact
Explores content-addressed storage across chunking, indexing, reclamation, and replication, with benchmark harnesses for inspecting each stage.
